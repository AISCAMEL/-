# UI/UX 設計（情報設計・導線）

共通基準は `../../reference/DESIGN-STANDARDS.md`。CVは `conversion-optimization`、操作保証は `accessibility` と併用。

## 作業手順
1. **ページ棚卸し**: 各ページに「唯一の目的」を割り当て、サイトマップ化。
2. **行動フロー設計**: 流入→理解→比較→行動の各段で離脱要因を特定し潰す。
3. **ワイヤー**: 情報の優先順位・CTA位置・フォーム項目数を PC/SP 両方で決める。
4. **状態設計**: 空・読込中・エラー・成功の見え方とマイクロコピーを用意。
5. **フォーム最適化**: 項目は最小限、ラベル明示、エラーは即時・具体・近接表示。

## 品質基準
- ファーストビューで価値とCTAが伝わる。主CTAは常に手の届く位置。
- タップ領域44px以上、入力数最小、キーボード操作とフォーカス順序が破綻しない。
- 1ページ1目的。導線は主→従が明確。

## 禁止事項
- 目的が重複するページの乱造。
- CTA過多で主従が消える設計。
- 意味のない装飾導線・長すぎるフォーム。

- [ ] 主要ページのワイヤー（PC/SP）がある
- [ ] CTA位置・フォーム項目・状態設計が定義済み
- [ ] マイクロコピーが用意された
