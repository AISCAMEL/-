# Web アートディレクション

目的: 以降の全工程の判断基準となる「デザインの憲法」を作る。
共通基準は `../../reference/DESIGN-STANDARDS.md` を参照（再掲しない）。
コピーの質は公式スキル **stop-slop**、配色理論は公式 **artifact-design / theme-factory** を活用してよい。

## 作業手順
1. **分析**: 事業・提供価値・ターゲット（ペルソナ）・KGI/CVを言語化。不明点は質問に残す。
2. **リサーチ**: 競合/参照を3〜5件分析し「良/陳腐/不採用」を仕分け。差別化軸を1つ決める。
3. **コンセプト**: デザインコンセプトを**1文**で定義。
4. **原則化**: コンセプトから以下を具体に落とす。
   - 配色方向（主色/役割/面積）
   - タイポ方向（和文/欧文/ジャンプ率/明朝orゴシック）
   - 写真・ビジュアルのトーン（被写体/明度/構図）
   - モーションの温度感
   - NG表現リスト
5. `art-direction.md` に出力。

## 品質基準
- 抽象語で終わらせず、後工程が迷わない具体に変換する。
- DESIGN-STANDARDS の10ルールと矛盾しない。
- 差別化軸が明確で、競合の模倣になっていない。

## 禁止事項
- 競合のデザイン/コピーの流用。
- 狙い（誰にどう効くか）のない「好み」判断。
- ペルソナ・CVゴール不在のまま見た目を語ること。

## 確認チェックリスト
- [ ] ペルソナ・提供価値・CVが明文化された
- [ ] コンセプト1文がある
- [ ] 配色/タイポ/写真/モーション/NG の原則が揃った
- [ ] 競合分析があり、差別化軸が1つに定まっている
