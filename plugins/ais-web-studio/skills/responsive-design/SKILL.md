# レスポンシブ設計

共通基準は `../../reference/DESIGN-STANDARDS.md`（ルール7: スマホ最適化）。検証は `quality-assurance` と併用。

## 作業手順
1. **モバイルファースト**で組み、上位ブレークポイントで拡張する。
2. ブレークポイント基準: スマホ <640 / タブレット 640–1024 / PC >1024（案件に応じ調整）。
3. 可変要素: フォントは `clamp()`、画像は `next/image` のレスポンシブ、グリッドは列数を段階変更。
4. タッチUX: タップ領域44px以上、要素間マージン確保、ホバー依存を作らない。
5. 各ブレークポイントで Playwright スクショを撮り、はみ出し/折返し/余白を確認・修正。

## 品質基準
- 横スクロールが発生しない（全幅要素のpadding/overflow管理）。
- 320px幅でも破綻しない。画像は歪まない（aspect比維持）。
- ナビは小画面でハンバーガー等に適切に変化し、操作可能。

## 禁止事項
- PC専用の固定幅・ホバーでしか出ない重要操作。
- 画像の引き伸ばし・テキストのはみ出し放置。
- デスクトップのみ確認して「対応済み」とすること。

## 確認チェックリスト
- [ ] 320〜1280+ で崩れ・横スクロール0
- [ ] タップ領域44px以上
- [ ] 画像アスペクト維持・ナビがSPで操作可能
- [ ] 3デバイス スクショ確認済み
