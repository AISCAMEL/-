# アクセシビリティ（WCAG 2.1 AA）

共通基準は `../../reference/DESIGN-STANDARDS.md`（§4 コントラスト）。検証は `quality-assurance` と併用。

## 作業手順
1. **コントラスト**: 本文4.5:1、大見出し3:1以上を確認。アクセント文字も背景との比を確認。
2. **キーボード**: 全操作がTabで到達・操作可能、フォーカスリングを消さない、順序が論理的。
3. **セマンティクス**: 見出し階層・landmark(header/main/nav/footer)・list/table の正しいマークアップ。
4. **ARIA**: ネイティブ要素優先、必要時のみ aria-* を付与（過剰付与しない）。
5. **画像/メディア**: 意味のある画像に説明的alt、装飾は alt=""、動画に字幕/代替。
6. **フォーム**: label と input の関連付け、エラーは text＋aria-describedby で通知。
7. スクリーンリーダー観点とキーボードのみ操作で通しテスト。

## 品質基準
- WCAG 2.1 AA 準拠。Lighthouse Accessibility ≥ 90。
- フォーカス可視・操作順序が自然・色だけに依存しない情報伝達。

## 禁止事項
- フォーカスリング除去のみ（代替なし）。
- 色のみで状態を伝える・画像内文字で重要情報を伝える。
- 無意味なARIAの乱用・見出しの飛ばし使い（装飾目的のh）。

## 確認チェックリスト

- [ ] キーボードのみで全操作可能・フォーカス可視
- [ ] landmark/見出し階層/alt/ラベル適正
- [ ] Lighthouse A11y ≥ 90
