# コンバージョン最適化（CRO）

共通基準は `../../reference/DESIGN-STANDARDS.md`。コピーの品質は公式スキル **stop-slop**、数値可視化は公式 **dataviz** を活用。

## 作業手順
1. **FV設計**: 3秒で「誰の/何の/なぜ良い」が伝わる主見出し＋サブ＋主CTA＋信頼の証（実績/権威/保証）。
2. **情報の順序**: 課題→解決→証拠(事例/口コミ)→差別化→料金→FAQ→CTA の流れで不安を順に解消。
3. **CTA**: 動詞＋得られる価値（例「無料で査定する」）。主CTAは1種、要所で繰り返す。副CTAは控えめ。
4. **摩擦の除去**: フォーム項目最小化、電話/LINE/メール等の選択肢、送信後の安心表示。
5. **信頼要素**: 実績数・顔/声・資格/許認可・保証・導入事例を適所に。誇大表現は不可。
6. **計測**: CV地点・イベント計測（GA4/Vercel Analytics）・主要導線のクリック計測を設計。
7. 可能なら仮説を1つ立て、A/B改善の余地を残す。

## 品質基準
- FV単体で価値とCTAが成立。主CTAが常に手の届く位置。
- 主張に必ず根拠（数値/事例/第三者）が伴う。

## 禁止事項
- 根拠のない誇大/最上級表現（景品表示法・薬機法リスク）。
- 虚偽の実績・サクラレビュー・カウントダウン等の不当な煽り。
- CTA乱立で主従が消える構成。

## 確認チェックリスト
- [ ] FVに主見出し/サブ/主CTA/信頼要素が揃う
- [ ] 情報順序が不安解消の流れになっている
- [ ] フォーム摩擦が最小・CV計測が設計済み
- [ ] 主張に根拠があり、誇大表現がない
