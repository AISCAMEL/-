# デザイン品質基準（単一ソース）

すべての Agent / Skill はこの基準を「共通の判断軸」として参照する。
各 Skill はここを再掲せず、自分の工程に関係する項目だけを引用して守らせること。

---

## 1. 10のゴールデンルール（絶対遵守）

1. **テンプレ感の排除** — 既製テーマをそのまま使った印象を与えない。グリッドの崩し・独自の余白設計・固有のタイポで「作り込み」を出す。
2. **安易なグラデーション禁止** — 装飾目的の多色グラデを多用しない。使うなら「同系色・2〜3%の明度差・面積は限定」。
3. **余白と文字の美しさ最優先** — 余白はデザインの主役。要素を詰め込まない。行間 1.6〜1.9、字間・1行最大全角40字前後。
4. **ファーストビューで勝つ** — 3秒で「誰の・何の・なぜ良いか」が伝わる。1メッセージ＋1主CTA。
5. **視覚的階層を明確に** — 見出し/本文のサイズ比は最低 1.5倍。太さ・色・余白で階層を作る。
6. **画像品質にこだわる** — 低解像度・歪み・素材感のない写真を使わない。暗部/明部/被写体の意図を確認。
7. **スマホ最適化** — モバイルファースト。タップ領域 44px 以上、横スクロール厳禁、親指動線を意識。
8. **目的のあるアニメーション** — 「視線誘導・状態提示・階層強調」のための動き。装飾だけの動きは消す。
9. **一貫性** — 色・間隔・角丸・影・タイポをトークン化し、全ページで統一。例外を作らない。
10. **独自性** — 競合や他社サイトの模倣をしない。参照はあくまでインプット、アウトプットは固有であること。

## 2. デザイントークン（全案件で定義する最小セット）

- **色**: brand / brand-2 / accent / ink / muted / bg / surface / line / 状態色(ok/warn/danger)
- **タイポ**: フォント / サイズスケール(例 12·14·16·18·21·26·32·42·56) / 行間 / 太さ
- **間隔**: 4の倍数スケール（4·8·12·16·24·32·48·64·96）
- **形**: 角丸(sm/md/lg/pill) / 影(sm/md/lg) / コンテナ最大幅
- 実装は CSS 変数 or Tailwind theme に集約し「1箇所で全体が変わる」状態にする。

## 3. タイポグラフィ基準

- 本文 16px 以上（モバイル含む）。見出しは明確なジャンプ率。
- 和文は Noto Sans JP / Hiragino 系、英数字は専用フォントで字面を整える。
- 1カラムの本文幅は 60〜75文字（和文35〜45字）に制限。
- 禁止: 中央揃えの長文、全文太字、3種以上の書体混在。

## 4. カラー／コントラスト基準

- 本文と背景のコントラスト比 **4.5:1 以上**、大見出しは 3:1 以上（WCAG AA）。
- 主要色は3色以内＋中立色。アクセントは「面積5%以内」で効かせる。
- 純黒(#000)・純白の大面積ベタ塗りは避け、わずかに色を含ませる。

## 5. レイアウト／余白基準

- セクション上下余白は本文の2〜4倍を基準に、リズムを一定化。
- 要素間は「近いものは近く、違うものは離す」（近接の法則）を徹底。
- 1画面に主役は1つ。視線の開始点と終着点（CTA）を設計する。

## 6. 画像・メディア基準

- 次世代フォーマット(WebP/AVIF)＋レスポンシブ画像(`next/image`)。
- 装飾画像に alt="" 、意味のある画像に説明的 alt。
- 動画は自動再生でも音声オフ・遅延読み込み・軽量化。

## 7. 禁止事項（全工程共通）

- ❌ Lorem ipsum や仮テキストを納品物に残す
- ❌ ダミーリンク(`href="#"`)を本番に残す
- ❌ 画像の引き伸ばし・アスペクト比破壊
- ❌ 根拠のない誇大表現・景品表示法/薬機法に触れる文言
- ❌ 競合サイトのデザイン/コピーの流用
- ❌ 1ページに CTA を乱立させ主従を失わせる
