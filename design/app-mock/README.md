# アプリ画面の見本（トップページ用の画像）

`screens.html?k=<名前>` を開くと、iPhone の枠つきでアプリ画面を表示します。
`node render.js <このフォルダの絶対パス> t_food t_cafe ...` で PNG（out-<名前>.png）に書き出し、
WebP にしてテーマの `assets/images/mock/` に置きます。

- ノーコード（テンプレート風）：t_food / t_cafe / t_beauty / t_home / t_corp / t_bakery / t_menu
- オリジナル開発：food / foodcard / salon / order / match / biz / learn / realty / event

写真はテーマの `assets/images/rn/` などから切り出したものです。店名・人名・数字はすべてサンプルです。
