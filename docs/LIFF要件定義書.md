# カーメル LIFF申込アプリ ― 要件定義書（第1弾：最小版）

> スコープ：**① 申込フォーム ＋ ② 審査結果表示**
> 目的：申込をLINE内で完結させ、LINE IDを確実に取得し、その場で審査結果を表示する
> 前提：既存のスコアリング（`Scoring.gs`）とWeb API（`WebApi.gs`）を流用する

---

## 1. 背景・目的

現行の申込は外部フォーム（ProLine）経由のため、次の弱点がある。LIFFで解消する。

| 現状の課題 | LIFFでの解決 |
|---|---|
| LINE IDが確実に取れず、結果を自動通知できない | `liff.getProfile()` で **userId を確実取得** |
| 住所が日付化する等、入力データが崩れる | **入力の型を制御**（日付=カレンダー、金額=数値、範囲=選択） |
| 申込後の離脱 | **その場で審査結果（ランク）を表示** |

---

## 2. スコープ

### 含む（第1弾）
- LINEリッチメニュー「申込」→ LIFF起動
- 3ステップの申込フォーム（ご状況／お客様情報／お仕事・ご希望）
- 送信時に userId を取得し、案件をスプレッドへ登録＋スコアリング
- 審査結果画面（ランク・スコア・月々目安・次の流れ）

### 含まない（第2弾以降）
- 書類アップロード（免許証・車検証・収入証明）
- 進捗マイページ
- 審査結果の自動プッシュ通知（別タスク）

---

## 3. 画面仕様

### 画面A：申込フォーム（3ステップ）
| STEP | 項目 |
|---|---|
| 1 ご状況 | 現在の事情（必須）／購入時期／これまでの審査社数 |
| 2 お客様情報 | 氏名（必須）／生年月日（必須・カレンダー）／電話（必須）／郵便番号 |
| 3 お仕事・ご希望 | 雇用形態（必須）／勤続 年・月（必須）／年収（必須）／月々支払可能額／他社借入／住居／頭金／保証人 |

- 進捗バー、戻る／次へ、必須バリデーション
- ※デモ実装済み：`docs/liff-demo/carmel-liff-demo.html`

### 画面B：審査結果
- ランクバッジ（A〜D）＋スコア＋月々お支払い目安
- ランク別メッセージ（例：A=通過可能性が高い／D=担当が個別相談）
- 「このあとの流れ」＋「LINEに戻る」

---

## 4. データ項目（スプレッド「ローン案件管理」へ）

既存の取込項目に準拠。LIFFから受け取り、`mapFormToLoan` と同じ列へ格納：
`受付日時, LINE_ID(userId), 顧客名, 生年月日, 電話番号, 郵便番号, 住所, 雇用形態,
勤続年数, 年収, 月額支払い可能額, 他社借入総額, 直近6ヶ月審査数, 信用情報,
債務整理歴, 自己破産歴, 頭金有無, 貯金額, 住居状況, 保証人有無` ほか。

→ 登録後 `runScoring` → `proposeCreditors` が自動で動く（既存フロー）。

---

## 5. 技術構成

```
LINE公式アカウント（リッチメニュー）
   └─ LIFFアプリ（LIFF ID）
        ├─ フロント：HTML/JS ＋ LIFF SDK（userId取得）
        └─ POST → Apps Script Web API（WebApi.gsを拡張）
             ├─ action=apply  … 申込を受付→案件登録→スコアリング→結果を返す
             └─ 返却：{ ok, caseId, score, rank, monthlyGuide }
```

### 追加で作るもの
| 種別 | 内容 |
|---|---|
| LINE Developers | LIFFアプリ登録（エンドポイントURL・スコープ profile） |
| フロント | 申込フォーム（デモをベースに、LIFF SDK連携を追加） |
| API | `WebApi.gs` に `action=apply` を追加（申込受付＋スコア返却） |
| リッチメニュー | 「申込」ボタン→ LIFF URL |

### 既存で流用するもの
- `Scoring.gs`（スコア計算）／`FormHandler.gs`（列マッピング）／`WebApi.gs`（token認証・土台）

---

## 6. セキュリティ
- API は既存の `token` 認証を使用（＋ LIFFのIDトークン検証を推奨）
- 個人情報を含むため HTTPS 必須（GAS Web Appは標準でHTTPS）

---

## 7. 作業ステップ（第1弾）
1. LINE Developers で LIFFアプリ登録（LIFF ID取得）
2. `WebApi.gs` に `action=apply` を追加（申込受付＋スコア返却）
3. 申込フォーム（デモ）に LIFF SDK連携を追加し、LIFFにデプロイ
4. リッチメニューに「申込」ボタンを設定
5. テスト（申込→登録→スコア→結果表示）

## 8. 目安期間
- 第1弾（①＋②）：**約2〜3週間**
