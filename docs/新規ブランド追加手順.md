# 新規ブランド／店舗の追加手順（オンボーディング）

> **毎回これを見れば追加できる**チェックリストです。システムは作り直しません。
> 1つの完成したシステムに「テナント（店舗）を登録」していくだけです。
> 所要時間の目安：電話番号を除けば **30分〜1時間**。電話番号は審査があるため別途数日。

## 1. 店舗アカウントを作成

1. 運営アカウント（super_admin）で管理画面にログイン → **「テナント管理」**
2. **「新規店舗を追加」** で入力：
   - 会社名・店舗名
   - 業種（例：車買取 / 美容室 / 飲食 など）
   - プラン（受付 / 営業 / 統合 …）
   - オーナーのメールアドレス
3. 保存すると、そのオーナー宛に**招待リンク**が発行されます。

> メールが届かない場合に備え、管理画面にも招待リンクが表示されます（手動で共有可）。

---

## 2. 招待メールを送る（店舗オーナーが初期設定）

1. 店舗オーナーが招待メールのリンクを開く → **パスワードを設定**
2. これで店舗オーナーが自分のアカウントでログインできるようになります
3. オーナーは自店の通知先メール・Slack等を設定

---

## 3. AIを業種に合わせて調整

1. 管理画面 → **「AI設定」**
2. 業種テンプレを選ぶと、その業種のFAQ・応対の下地が入ります
3. 各店に合わせて微調整：
   - **FAQ**（よくある質問と回答）
   - **受付種別**（例：車買取なら「出張査定／持込査定／オンライン査定／来店商談」）
   - 営業時間・定休日・担当者転送先
4. **「AI応対テスト」** で会話を一通り確認

---

## 4. メール送信元ドメインを設定（Resend）

お客様・スタッフ宛てに「そのブランドのドメイン」から届くようにします。

### 4-1. ドメインがまだ無い場合：Resendで認証（初回のみ）
1. [Resend](https://resend.com) → **Domains** → **Add Domain**
2. `send.ブランド名.com` のような**サブドメイン**を入力
3. 表示されたDNSレコード（MX / TXT ×2〜3）を、そのドメインのDNS管理画面に貼る
4. **Verify** → 緑の「Verified」になれば完了
   - ※詳細は `docs/quickstart-openrouter-resend.md` 参照

> 既に認証済みなら（例：`send.buymo.me` / `send.aisjaltd.com`）この手順は不要。

### 4-2. 送信元アドレスを設定
- **テナントごとに設定できる場合**：管理画面のテナント設定で `送信元メール` に
  `ブランド名 <noreply@send.ブランド名.com>` を入力
- **共通設定（MAIL_FROM）で運用する場合**：Render の `aioperator-backend` →
  **Environment** → `MAIL_FROM` を `ブランド名 <noreply@send.ブランド名.com>` に設定 → 保存（自動再デプロイ）

### 4-3. 方針メモ（ブランドを増やすとき）
- **自社ブランド**：ブランドごとにサブドメインを運営側で認証（ベスト：ブランド一致＋到達率の隔離）
- **他社へ再販（相手が自社ドメインを持つ）**：相手にDNSレコードを渡して貼ってもらう
- **未設定のテナント**：共通ドメイン（`send.aisjaltd.com`）にフォールバックでも可

## 5. 電話番号を手配（Twilio）

> ここが唯一「毎回ある程度手間がかかる」部分。日本は本人確認＋規制対応が必要。
> 詳細手順は `docs/twilio-setup.md` を参照。

1. **番号の種類を選ぶ**
   - 050（National）：**¥742/月**・安価（SMS無し・音声のみ）
   - 市外局番（Local）：¥3,125/月・地域番号
2. **規制バンドル（Regulatory Bundle）を提出**
   - 本人確認書類＋「Japan Regulatory Bundle Application」（署名入り）
   - 審査：平均7日
3. **番号を購入**（アカウントUpgrade＝カード登録が必要）
4. **Voice Webhook を設定**：
   `https://aioperator-backend-eks8.onrender.com/api/twilio/incoming-call`
5. 管理画面で **番号をそのテナントに割当**

> 名義の選択：各社が自社名義で取得（推奨）／運営名義でまとめ取得→振り分け、の2通り。

---

## 6. 請求を設定（Square 自動請求）

1. 管理画面 → テナント詳細 → **「当月の請求書を発行」**
2. 基本料＋従量＋税を自動計算し、Squareで請求書を発行→お客様にメール送信
3. 毎月の締めで発行（詳細は `docs/square-billing.md`）

## よくある質問

**Q. 新しい会社ごとにシステムを作り直すの？**
A. いいえ。システムは1つ。**テナントを登録するだけ**です。精度・機能の改善は1回で全社に反映されます。

**Q. 一番時間がかかるのは？**
A. 電話番号の規制審査（数日）。番号以外は即日セットアップ可能です。

**Q. メールは無料のまま？**
A. 無料枠は3,000通/月・100通/日。通知用途なら当面無料で運用できます。超えたらResend Pro（$20/月〜）。
