# 自社導入ガイド（合同会社アイズ／AUC-AGENT）

車オークション代行・買取査定の電話受付を、AIオペレーター24で自社運用するための手順です。
管理画面はすでに「オークション代行のアイズ」仕様でプリセット済み（挨拶文・FAQ・査定予約・買取キャンペーン）。
あとは接続していくだけです。「🚀 開業セットアップ」画面の進捗に沿って進めてください。

## この業種テンプレートに入っているもの

「業種テンプレート」→「オークション代行・買取（自社／アイズ向け）」を適用すると一括投入されます：

- **挨拶文**：「オークション代行のアイズ、AI受付です。購入代行・出品代行・買取査定など、ご用件をお話しください。」
- **FAQ**：営業時間/対応エリア・購入代行の流れと手数料・出品/買取・買取査定・陸送/納期・会員登録・名義変更
- **AI架電シナリオ**：買取査定のご提案／見積もり後の後追い／会員フォロー（提案）

## 想定される着信と、AIの動き

| 着信 | AIの対応 |
|---|---|
| 「車を売りたい・査定して」 | 車種・年式・走行距離・状態を聞き取り → 出張/持ち込みを確認 → 査定予約へ |
| 「購入代行したい」 | 希望車種・予算を聞き取り → 担当バイヤーへ折り返し手配 |
| 「手数料は？会員登録は？」 | FAQで即回答（落札価格帯別の定額・会員登録は無料） |
| 「陸送費・納期は？」 | エリアを聞き取り → 担当より概算案内へ |
| 営業時間外・不在 | 24時間AIが一次受付し、要約をメール通知。取りこぼしゼロ |

## 導入ステップ（開業セットアップ画面と対応）

1. **AI接続**（実費ほぼ0）… OpenRouter/OpenAI キーを Render に設定（`docs/quickstart-openrouter-resend.md`）
2. **メール通知**… Resend キー＋通知先を自社アドレスに（着信の要約が届く）
3. **業種テンプレ適用**… 上記「オークション代行・買取」をワンクリック適用
4. **挨拶文・営業時間**… 平日10-19時・土10-17時・日休みでプリセット済み（必要なら調整）
5. **FAQ**… 手数料・エリアなど自社の最新内容に微調整
6. **通知先メール**… 着信をどこで受けるか
7. **電話番号**（唯一の実費）… Twilio接続で実際に着信（`docs/twilio-setup.md`）
8. **（任意）Googleカレンダー連携**… 出張査定の予約をスタッフ予定と突合し重複防止（`docs/google-calendar-setup.md`）

## 買取フローの一気通貫（自社での使い方）

```
着信（売りたい）→ AIが車種/年式/走行を聞き取り → 査定予約（重複しない枠）
   → 連絡先リストに追加（買取査定カテゴリ）→ 見積もり後の後追いはAI架電
   → 成約/見送りをステータス管理
```

## 費用の目安（自社・月50件・平均3分想定）

- 月額 約¥2,000前後（サーバー無料枠時）。有料枠でも月¥7,000程度。
- 買取1件成約で数万〜数十万の粗利 → 取りこぼし1件防ぐだけで回収。

詳しくは `docs/cost-analysis.md`。
