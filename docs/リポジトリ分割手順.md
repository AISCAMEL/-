# リポジトリ分割手順（バイモダイレクトを専用リポジトリへ独立）

## なぜ分けるのか（重要）

現在このプロジェクトは **`AISCAMEL/-`（名称「カーメルメンバー」・公開/Public）** の中にあります。
公開リポジトリなので、**社外秘のポータル内容が誰でも閲覧できる状態**です：

- `site/partner/*.html`（加盟店マニュアル・コンプラ資料・営業資料・スタッフ情報）
- `site/admin/*.html`（本部コンソール）
- `docs/査定マニュアル.md` `docs/料金一覧.md` `docs/契約書・規約_雛形.md` など

> ✅ パスワードハッシュ等（`server/partners.json` / `access.log` / `data/`）は **Git に含まれていません**（実行時に生成）。`.gitignore` で今後も除外済み。
> 🔴 ただし上記の **HTMLやドキュメントは公開状態**。バイモを専用リポジトリに移し、**非公開(Private)** にすることで解決します。

## おすすめ構成

| リポジトリ | 内容 | 公開設定 |
|---|---|---|
| **`AISCAMEL/buymo`（新・専用）** | バイモダイレクト一式（`site` / `server` / `gas` / `docs` / Docker・Render設定） | **Private（非公開）を強く推奨** |
| `AISCAMEL/-`（カーメルメンバー） | 他の用途に戻す（バイモのファイルは削除） | 現状のまま |

Render／VPS は Private リポジトリでも問題なく連携できます（デプロイ時にアクセス許可するだけ）。

## 手順A. バイモのファイルだけを「まっさらな履歴」で `buymo` へ入れる（混ざり防止）

> ⚠️ `-` を丸ごと push する方法は使いません。`-` は寄せ集めリポジトリで、
> 他ブランチ・過去履歴・他プロジェクトが `buymo` に混ざる恐れがあるためです。
> 代わりに **今のバイモのファイルだけ** を、履歴のない新しいリポジトリとしてコピーします。

```bash
# 1. バイモのファイルだけを取り出す（.git を含めない = 履歴を持ち込まない）
git clone --depth 1 -b claude/car-appraisal-manual-5p3ubf https://github.com/AISCAMEL/-.git src
rm -rf buymo-clean && mkdir buymo-clean
# src の中身（.git 以外）を buymo-clean へコピー
cp -a src/. buymo-clean/ && rm -rf buymo-clean/.git
cd buymo-clean

# 2. まっさらな履歴で初期化
git init -b main
git add -A
git commit -m "初期コミット: バイモダイレクト（AISCAMEL/- から分離）"

# 3. buymo へ push
git remote add origin https://github.com/AISCAMEL/buymo.git
#   ※ buymo に既存の別内容があり、それを置き換えてよい場合のみ --force を付ける
git push -u origin main --force
```

> **`buymo` に残したい別の内容がある場合**は `--force` を付けず、
> 先に buymo の中身を別ブランチへ退避するか、**バイモ専用の新しい空リポジトリ**
> （例：`AISCAMEL/buymo-portal`）を作って push 先にしてください。混ざりを確実に避けられます。

## 手順B. `buymo` を「非公開(Private)」にする

1. https://github.com/AISCAMEL/buymo を開く
2. **Settings（設定）→ 一番下「Danger Zone」→「Change repository visibility」**
3. **「Make private」** を選択して確定

## 手順C. 公開リポジトリ `-` からバイモを取り除く

`buymo` へ移したら、公開リポジトリ側に社外秘が残らないようにします。

```bash
# -（公開）側の作業コピーで
git rm -r site server gas docs Dockerfile docker-compose.yml render.yaml
git commit -m "バイモダイレクトを AISCAMEL/buymo へ分離"
git push origin main
```

> ⚠️ 「公開リポジトリの**過去の履歴**にも社外秘を一切残したくない」場合は、
> ファイルを消すだけでは履歴に残ります。その場合は
> `-` 側で `git filter-repo`（履歴からの完全削除）が必要です。ご希望なら手順を用意します。
> 最も確実なのは、**`-` を作り直す or 一旦 Private 化**する方法です。

## 分割後のデプロイ（Render）

デプロイ元リポジトリが `buymo` に変わるだけで、手順は `docs/デプロイ手順.md` の F 章と同じです。

1. Render →「New +」→「Blueprint」→ **`AISCAMEL/buymo`** を選択
2. Private リポジトリなので、初回に GitHub アクセス許可を求められたら承認
3. `render.yaml` が読み込まれ、自動でデプロイ

一般公開サイト（静的LP）だけを Netlify 等に別途出す場合も、`buymo` の `site/` を使えます。
