# 自社導入ガイド（車買取専門店）

車買取専門の電話受付を、AIオペレーター24で自社運用するための手順です。
管理画面はすでに「車買取専門店」仕様でプリセット済み（挨拶文・FAQ・査定予約・買取キャンペーン）。
あとは接続していくだけです。「🚀 開業セットアップ」画面の進捗に沿って進めてください。

## この業種テンプレートに入っているもの

「業種テンプレート」→「車買取専門店」を適用すると一括投入されます：

- **挨拶文**：「車買取専門店、AI受付です。買取査定のご依頼を承ります。お車の車種・年式などを教えてください。」
- **FAQ**：営業時間/対応エリア・買取査定・出張査定・必要書類・ローン残債・事故車/不動車・査定額の考え方
- **AI架電シナリオ**：買取査定のご提案／査定後の後追い／買い替え時期のご案内

## 想定される着信と、AIの動き

| 着信 | AIの対応 |
|---|---|
| 「車を売りたい・査定して」 | 車種・年式・走行距離・状態を聞き取り → 出張/持込を確認 → 査定予約へ |
| 「出張査定に来てほしい」 | 場所と希望日時を聞き取り → 重複しない枠で予約 → 担当割当 |
| 「ローンが残ってても売れる？」 | 残債精算に対応と案内 → 車種・残額を聞き取り → 担当へ |
| 「事故車・不動車だけど」 | 査定対象と案内 → 状態を聞き取り → 担当へ |
| 「必要な書類は？」 | 車検証・認印・本人確認書類を即回答（FAQ） |
| 営業時間外・不在 | 24時間AIが一次受付、要約をメール通知。夜間の売却相談も取りこぼしゼロ |

## 導入ステップ（開業セットアップ画面と対応）

1. **AI接続**（実費ほぼ0）… OpenRouter/OpenAI キーを Render に設定（`docs/quickstart-openrouter-resend.md`）
2. **メール通知**… Resend キー＋通知先を自社アドレスに（査定依頼の要約が届く）
3. **業種テンプレ適用**… 「車買取専門店」をワンクリック適用
4. **挨拶文・営業時間**… 平日10-19時・土10-17時・日休みでプリセット済み（必要なら調整）
5. **FAQ**… 買取エリア・出張範囲・キャンペーンなど自社の最新内容に微調整
6. **通知先メール**… 査定依頼をどこで受けるか
7. **電話番号**（唯一の実費）… Twilio接続で実際に着信（`docs/twilio-setup.md`）
8. **（任意）Googleカレンダー連携**… 出張/持込査定の予約をスタッフ予定と突合し重複防止（`docs/google-calendar-setup.md`）

## 買取フローの一気通貫（自社での使い方）

```
着信（売りたい）→ AIが車種/年式/走行/残債を聞き取り → 査定予約（重複しない枠）
   → 連絡先リストに追加（査定見込みカテゴリ）→ 査定後の後追いはAI架電
   → 成約/見送りをステータス管理
```

## 費用の目安（自社・月50件・平均3分想定）

- 月額 約¥2,000前後（サーバー無料枠時）。有料枠でも月¥7,000程度。
- 買取1件成約で数万〜数十万の粗利 → 取りこぼし1件防ぐだけで回収。

詳しくは `docs/cost-analysis.md`。

## 法令の注意（買取業）
- 電話では確定査定額を約束しない（確定は現車確認後）。テンプレのAIもその方針で応対します。
- 古物営業・本人確認等の実務は自社の運用ルールに従ってください。
