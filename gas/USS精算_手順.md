# USS精算書 → 加盟店請求書 自動化 セットアップ手順（`USS精算.gs`）

USSの**パスワード付き精算書メール**を自動で開封→明細転写→**本部手数料を自動計算**→
**加盟店向け請求書PDFを自動生成**→**入金消し込み**まで行います。

---

## 全体フロー

```
USS精算書メール（PDF・パスワード付き）
 └→ Gmail自動検知 → PDF.co で自動復号（パスワードは自動入力）
      └→「USS精算_明細」へ1台ずつ転写
           └→ スタッフが各行に「加盟店」「仕入れ」を入力
                └→ 粗利＝成約金額−仕入れ／本部手数料を自動計算
                     └→ generateInvoices() が件名×加盟店ごとに請求書PDF生成
                          └→ 銀行CSVと突合して入金消し込み（システム管理）
```

## 手数料の計算（確定仕様）

| 項目 | 式 |
|---|---|
| 粗利 | 成約金額 − 仕入れ |
| 本部手数料合計 | **落札11,000（固定）＋ 振込550（固定）＋ 粗利×5%** |
| 加盟店請求額 | 本部手数料合計 |

> 「仕入れ」はUSS精算書に載らない（USSは加盟店の原価を知らない）ため、
> **明細シートの「仕入れ★入力」列にスタッフが入力**します。入力すると粗利5%が自動計算されます。

請求書上の配置：**落札料欄＝11,000／委託手数料欄＝振込550＋粗利5%**（既存様式に合わせています。変更は `buildInvoicePdf_` で調整可）。

## 1. Config.gs の設定（⑦⑧）

```js
// 取込
USS_MAIL_FROM: "uss",  USS_MAIL_SUBJECT: "精算",  USS_PDF_PASSWORD: "U3472",
USS_DECRYPT_MODE: "pdfco",  PDFCO_API_KEY: "xxxx",   // "none"ならCSV運用（PDF.co不要）
// 手数料
USS_FEE_RAKUSATSU: 11000,  USS_FEE_FURIKOMI: 550,  USS_ROYALTY_RATE: 0.05,
// 請求書 発行元（合同会社アイズ）
INV_ISSUER_TEL: "0246-38-4641",  INV_BANK: "PayPay銀行 … 普通 3196378", …
// 入金
USS_BANK_CSV_FOLDER_ID: "",  USS_MATCH_TOLERANCE: 0,
```

## 2. 初回実行（GASエディタで関数を選び実行）

1. `setupUss()` … シート作成
   （USS精算_明細／入金消し込み／請求書控え／加盟店マスタ）
2. `installUssTriggers()` … 取込15分毎・消し込み毎日9時
   - 初回は権限承認（Gmail/Drive/外部通信/スプレッドシート）→ 許可

## 3. 日々の運用

1. 精算書メールが届くと自動で「USS精算_明細」に転写（LINE/ Slack通知）
2. 明細の **「加盟店」「仕入れ」** を入力（粗利5%が自動計算）
3. `generateInvoices()` を実行（または任意でトリガー化）
   → 件名×加盟店ごとに**請求書PDF**を生成、「請求書控え」に記録
4. 銀行の入出金CSVを `USS入金CSV` フォルダに置く → `runReconciliation()` で消込

## 4. 動作確認

| 関数 | 内容 |
|---|---|
| `testFee()` | 手数料計算（例：粗利30万→固定11,550＋5%15,000） |
| `testParseUssText()` | サンプル文字列の抽出 |
| `runUssSettlement()` | 実メール取込 |
| `generateInvoices()` | 請求書PDF生成 |
| `runReconciliation()` | 入金消し込み |

## 加盟店マスタ（宛先）

`加盟店マスタ` シートに「加盟店名／〒／住所／敬称／メール」を登録すると、
請求書の宛先に反映されます（未登録なら加盟店名のみ表示）。

## USSフォーマット調整（重要）

`parseUssText_()`／`parseUssCsv_()` は汎用抽出です。実際の精算書サンプルを1件いただければ、
**出品NO・成約金額・USS各手数料**の抽出精度を実物に合わせて仕上げます（唯一の実物合わせ箇所）。

## 費用の目安

- PDF.co：1通あたり数円程度（月数百円〜）。CSV運用（`USS_DECRYPT_MODE:"none"`）なら無料。
