=== カーメル AIチャットボット（本番版 v1.6.0）===

WordPress用プラグインです。テーマファイルの編集は不要です。
このプラグイン1つで、AI自動応答・FAQ学習・実在庫からの車種提案・
申込/問い合わせCTA・有人対応（メール/Slack/LINE WORKS通知・Slack双方向）まで動きます。


■ これは何を使う？（プラグイン or テーマ？）
→ 「プラグイン」です。テーマやfunctions.phpへの貼り付けは一切不要。
   いま入っている「カーメル AIチャットボット」を、このv1.6.0で置き換えるだけです。


■ 導入（置き換え）手順
1. WordPress管理画面 →「プラグイン」を開く。
2.（推奨）バックアップとして、現在の carmel-chatbot は念のため残すか、
   既存zipを手元に保存しておく。
3. このまま上書き更新する場合：
   「プラグイン」→「新規追加」→「プラグインのアップロード」→ 本zipを選択
   → インストール時に「既存を置き換えますか？」と出たら「アップロードして置換」。
   ※ 設定・FAQ・会話ログはデータベースに残るため消えません。
4. 「有効化」されていることを確認。


■ 最初にやること（必須）
1.「チャットボット」→「基本設定」
   ・OpenRouter APIキー（sk-or-v1-...）を貼り付け
     - https://openrouter.ai/ 登録 →「Keys」で発行 →「Credits」で少額チャージ
   ・「チャットボットを有効化」にチェック →「保存する」
2. サイト右下に「💬 相談する」が出れば成功。試しに話しかけてください。


■ 機能と設定場所
【基本設定】
 ・APIキー / 使用モデル（無料モデル→安価モデルへ自動フォールバック）/ 応答の長さ / ログ保存
 ・有人対応：ON/OFF、営業時間、営業曜日、通知先メール
 ・Slack通知(一方向 Webhook)
 ・Slack双方向(Botトークン xoxb- + チャンネルID)：営業時間内に担当者がSlackで返信→チャット表示
 ・LINE WORKS通知(Client ID/Secret/Service Account/Bot ID/トークルームID/秘密鍵PEM)
【応答・人格】
 ・ボットの性格・ルール（システムプロンプト）。会話の進め方・CTA判断は内部で自動制御。
【学習データ(FAQ)】
 ・Q&Aの追加/編集。質問に関連するものだけ自動でAIに渡す（RAG）。
【会話ログ】
 ・実際のやり取りを確認。FAQ追加のヒントに。
【見た目設定】
 ・ボット名 / あいさつ / 色 / LINE相談URL / 電話番号
 ・審査申込ページID / お問い合わせページID（CTAの飛び先。公開URLを自動解決）


■ 主な動き
 ・会話：悩みを1つずつ深掘りし、申込意欲が高まった場面でCTA（審査申込/お問い合わせ/LINE/電話）。
 ・候補：返答の下にタップで進めるクイック返信を表示。
 ・車種提案：車・予算の話題のとき、公開中の在庫(portfolio)から条件に合う車を
   写真・価格・月々・詳細リンク付きで提案。新着は自動反映、売却分は自動で消える。
 ・有人対応：
     営業時間内 + Slack双方向あり → 担当者がSlackでライブ返信（20秒未応答ならフォームへ）
     営業時間内 + Slackなし        → 連絡先フォーム＋メール/LINE WORKS通知
     時間外                        → フォーム＋翌営業日連絡＋AI継続


■「学習」について
 モデル自体の再学習はできません。「学習データ(FAQ)」に登録した内容を毎回AIへ渡します。
 → FAQを足す＝新しい知識を覚える、と同じ効果。
 金利・在庫など変動条件は断定せず「状況により異なる→相談へ」を推奨。


■ 二重表示の防止
 以前の右下チャット（Genspark等の埋め込み）が残っている場合は削除してください。


■ 安全・コスト
 ・APIキー等はサーバー側(DB)に保存。フロントには出ません。
 ・既定モデルは安価（1問おおむね0.01〜0.05円目安）。max_tokensで調整可。
 ・審査可否・金利・支払額を断定させないルールは法令/トラブル防止のため残す推奨。


■ 動作に必要な前提
 ・OpenRouter APIキー（必須）。
 ・在庫提案：在庫プラグイン(carmel-stock-ui)で portfolio に車両登録があること。
 ・Slack双方向：Slack Botトークン＋チャンネル、Botをチャンネルに招待。
 ・LINE WORKS：Developer Consoleでサービスアカウント/Bot発行。
 ※未設定の機能は自動的にオフになり、他機能の動作には影響しません。
