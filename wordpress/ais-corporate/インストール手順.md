# AIS コーポレート プラグイン｜インストール手順

WordPress に **アップロード→有効化するだけ**で、コーポレートサイトの新デザインが
フロントページに一括適用されます。

## ① 導入（いちばん簡単）

1. 配布された **`ais-corporate.zip`** を用意
2. WordPress 管理画面にログイン
3. 左メニュー **プラグイン → 新規追加 → プラグインのアップロード**
4. `ais-corporate.zip` を選び **今すぐインストール**
5. **プラグインを有効化**

→ これで**トップページが新デザインに切り替わります**。
　管理画面上部に「✅ 適用しました」と表示され、「サイトを表示」から確認できます。

## ② 元に戻したいとき

- プラグインを **無効化** すると、フロントページ設定は**元の状態に戻ります**。
- 自動作成された固定ページ「ホーム」は残ります（必要なら手動で削除可能）。

## ③ 手動で設置する場合（任意）

- **固定ページに適用**：固定ページ編集 → 右側「ページ属性」→ テンプレートで
  **「AIS コーポレートTOP（全幅・独自ヘッダー）」** を選択。
  その後 **設定 → 表示設定** でそのページを「ホームページ」に指定。
- **本文に埋め込み**：任意の固定ページ本文に次のショートコードを貼り付け
  ```
  [ais_corporate_home]
  ```

## ④ デザインの変更

- 色・フォント・余白は **`assets/css/theme.css` 1ファイル**に集約されています。
  ここを書き換えると、サイト全体の見た目が一括で変わります。
- 文言・ブランドの並びは `ais-corporate.php` 内のマークアップ、または
  各ブランドのリンク先（現在は仮の `#`）を編集してください。

## 注意

- 独自の全幅レイアウトのため、**現在お使いのテーマのヘッダー/フッターは表示されません**
  （コーポレートTOPを綺麗に見せるための仕様です）。
- 下層ページは通常どおりテーマが使われます。コーポレート下層も同デザインにしたい場合は
  別途ページを作成し、同じテンプレートを割り当ててください（ご相談ください）。
