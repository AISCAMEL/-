合同会社アイズのコーポレートサイト（車8割・IT2割／上質デザイン）を、固定ページテンプレートとして一括適用します。

== Description ==

このプラグインを有効化すると、合同会社アイズのコーポレートTOP（上質・高級感デザイン）を
WordPress に一括適用します。既存テーマに依存せず、独自の全幅レイアウトで表示します。

* 有効化だけでフロントページを新デザインに自動設定（一括リニューアル）
* 既存テーマのヘッダー/フッターを使わない全幅レイアウト
* ショートコード [ais_corporate_home] でも設置可能
* 無効化するとフロントページ設定は元に戻ります（作成した固定ページは残ります）
* デザインは assets/css/theme.css 1枚で色・フォント・余白を一括変更可能

== Installation ==

1. 管理画面 → プラグイン → 新規追加 → 「プラグインのアップロード」
2. ais-corporate.zip を選択してインストール
3. 「有効化」をクリック → フロントページが新デザインになります

手動で設置する場合:
* 固定ページを新規作成し、ページ属性の「テンプレート」で
  「AIS コーポレートTOP（全幅・独自ヘッダー）」を選択 → 設定 → 表示設定 でフロントページに指定
* または任意の固定ページ本文に [ais_corporate_home] を貼り付け
