# AIS Premium サイト — 導入手順・検証結果・残課題（Stage 1）

添付デザインキット（AIS_PREMIUM_CLAUDE_CODE_KIT）を基準に、WordPress ブロックテーマ
**AIS Premium** と管理プラグイン **AIS Business Hub** を実装しました。

## 構成
- `ais-premium-theme/` … ブロックテーマ（デザイン・テンプレート・CSS/JS）
- `ais-business-hub/` … 管理プラグイン（事業CPT・サイト設定・ホーム描画・フォーム・一括セットアップ）

配布ZIP：`ais-premium-theme.zip` / `ais-business-hub.zip`

## 導入手順（ステージング推奨）
1. **バックアップ**を取得（本番は直接触らない）。
2. 管理画面 → プラグイン → 新規追加 → アップロード → `ais-business-hub.zip` → 有効化。
3. 外観 → テーマ → 新規追加 → アップロード → `ais-premium-theme.zip` → 有効化。
4. 管理画面 → **AIS Business Hub → 一括セットアップ** → 確認にチェックして実行。
   - 固定ページ11種・事業9件・ニュース用カテゴリを作成し、トップを新デザインに設定します（**冪等**：再実行しても既存は保持）。
5. **AIS Business Hub → サイト設定**で、ヒーロー文言・実績数値・理念・通知先メールを編集。
6. 各事業は **AIS事業** 一覧から文言・画像（アイキャッチ）を編集。

元に戻す：一括セットアップ画面の**ロールバック**でフロント設定を復元（作成物はゴミ箱選択可）。

## 残課題（正直な状態・次段階）
1. **実写真**：ヒーロー等は権利確認済みの実写に差し替え前提のプレースホルダ。SVGは仮素材。
2. **実績数値・ニュース**：モックの数値/記事は**サンプル**。事実確認・承認後に差し替え（既定で注記表示）。
3. **AI機能**：AIコンシェルジュ／AI記事生成は**UI・導線のみ**。外部API未接続（キー設定後に有効化予定、現状「動作済み」と偽らない）。
4. **全7フォーム個別ページ**：総合＋トピック別は実装済み。買取/輸出/パートナー等の専用ページ化は次段階。
5. **各事業ページの作り込み**（本文・図・CTA詳細）、SEO構造化データ、301リダイレクト設計、受入チェックリスト全項目の実機確認。
6. **メディアライブラリへのSVG取り込み**（現状はプラグインURL参照）。

## セキュリティ・方針
- REST/管理操作に nonce・権限（manage_options / edit_post）・サニタイズ・エスケープを適用。
- フォームは同意記録・ハニーポット・必須検証。通知は `wp_mail`。
- 本番反映・管理画面変更は利用者の承認のもとで実施してください。
