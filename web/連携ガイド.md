# 🔌 外部連携ガイド（Square / BASE / 楽天 / Yahoo! / Amazon）

これらは外部サービスです。**接続にはあなた（運営）の加盟店アカウントとAPIキー**が必要です。
アプリ側の連携コード・管理画面は実装済みなので、`.env.local` にキーを設定すれば有効になります。

## 役割分担
| 用途 | サービス | 何をする |
|------|---------|---------|
| 決済 | **Square** | 講座/プレミアムのサブスク・対面決済 |
| 物販 | **BASE** | オンラインショップ本体（在庫・注文・配送）＋仕入れ先商品の自動掲載 |
| 販売チャネル | 楽天 / Yahoo! / Amazon | 多店舗展開 |

## 設定する環境変数（`.env.local`）
```
# 決済：Square（Square Developer で取得）
SQUARE_ACCESS_TOKEN=
SQUARE_LOCATION_ID=
NEXT_PUBLIC_SQUARE_APPLICATION_ID=

# 物販：BASE（BASE Developers でアプリ登録→OAuthでアクセストークン取得）
BASE_API_ACCESS_TOKEN=
NEXT_PUBLIC_BASE_SHOP_URL=   # 例: https://iwasawa.thebase.in

# 販売チャネル（各出店契約・API利用申請が必要）
RAKUTEN_API_KEY=
YAHOO_API_KEY=
AMAZON_SP_API_TOKEN=
```

## 仕入れ先 → BASE 自動掲載の使い方
1. 管理画面 `/admin/suppliers`（仕入れ先・BASE）を開く
2. 「仕入れ先を登録」→「仕入れ商品を登録」（商品名・販売価格など）
3. `BASE_API_ACCESS_TOKEN` を設定していれば、商品の「**BASEに掲載**」ボタンで
   BASE API（`items/add`）に自動出品され、`BASE掲載中`になります
4. 未接続のときは「未掲載」のまま、掲載メッセージに未接続の案内が出ます
5. 接続状況は `/admin/channels`（チャネル・決済）で確認できます

## 各サービスの取得先（参考）
- Square：https://developer.squareup.com/
- BASE：https://developers.thebase.in/
- 楽天：楽天RMS / 出店契約
- Yahoo!：Yahoo!ショッピング ストアクリエイターPro
- Amazon：Amazon 出品用アカウント / SP-API

## いまの実装範囲
- ✅ 仕入れ先・仕入れ商品の登録／削除（管理画面）
- ✅ BASE への出品コード（キー設定で有効・`items/add`）＋掲載状況の記録
- ✅ 各チャネル・Square の接続状況表示
- ⬜ 楽天/Yahoo!/Amazon への実出品、Square 決済フローの本実装
   （各サービスの審査・API仕様に沿って順次。アカウント準備後に対応可能）
